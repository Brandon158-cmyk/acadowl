A high-contrast, minimal design system for building consistent school management experiences. Built for clarity, speed, and scalability.

Copy Scale

Multi-line body text. Higher line-height than Label for comfortable reading.

Copy 16 — Used in modals, announcement bodies, and detail views where text has room to breathe.

Copy 14 — The most commonly used body text size. Suitable for descriptions, notes, and longer form content within the interface.

Copy 13 — Secondary text and views where space is at a premium. Used in tooltips, helper text, and metadata.

Design Principles

The values that guide every decision in the Acadowl design system.

Clarity over cleverness

Dense data must be immediately readable. Every design decision should reduce cognitive load, not add to it. If something needs to be explained, it should be redesigned.

Semantic color only

Color is used to encode meaning — success, warning, failure, neutral. It is never used decoratively. A red element always means an error or critical state.

Consistency at every scale

A badge in a table and a badge in a modal are identical. Spacing tokens, typography scales, and radius values are shared globally. Exceptions should be rare and intentional.

Accessible by default

All text meets WCAG AA contrast ratios. Interactive elements are keyboard navigable. Status is never conveyed by color alone — always paired with a text label or icon.
